# Ограниченный ИИ-ассистент

ИИ-ассистент Loom подготавливает черновик текстового материала для выбранного
проекта или задачи. Он не изменяет проекты, задачи и существующие материалы и
не сохраняет результат без отдельного подтверждения пользователя.

## Сценарий

1. Пользователь открывает проект и нажимает `ИИ-ассистент`.
2. Выбирает проект целиком или конкретную задачу.
3. Формулирует запрос длиной от 10 до 1500 символов.
4. Edge Function проверяет сессию и доступ пользователя к выбранному контексту.
5. OpenAI Responses API при необходимости использует веб-поиск и возвращает
   название, Markdown и список источников.
6. Пользователь проверяет и редактирует черновик.
7. Только кнопка `Сохранить материал` создаёт материал и его связь.

## Ограничения

- только создание нового текстового материала;
- не более 10 запросов за последние 24 часа на пользователя;
- до 12 веб-источников в результате;
- до 30 000 символов в черновике;
- ключ OpenAI никогда не передаётся во фронтенд;
- источники сохраняются в Markdown вместе с материалом.

Лимит можно изменить секретом `AI_DAILY_LIMIT`. Неудачные запросы также
учитываются: это ограничивает расходы при повторяющихся ошибках или
злоупотреблении.

## Секреты Supabase

В `Project Settings → Edge Functions → Secrets` должны быть заданы:

```text
OPENAI_API_KEY
OPENAI_MODEL=gpt-5.6-terra
```

Не добавляйте `OPENAI_API_KEY` в Vercel, `.env.example`, GitHub или исходный
код. В браузере используются только обычная сессия Supabase и публичный anon
key.

## Развёртывание

Миграция `202607290001_ai_assistant_usage.sql` создаёт закрытый журнал запросов
для контроля лимита. Таблица доступна только роли `service_role`.

После отправки изменений в `main` workflow `Database migrations`:

1. проверит все миграции на чистой локальной базе;
2. применит миграцию к рабочей базе;
3. развернёт Edge Function `ai-material-draft`.

## Проверка

1. Дождитесь успешного workflow `Database migrations`.
2. Откройте проект Loom и нажмите `ИИ-ассистент`.
3. Выберите задачу и выполните тестовый запрос.
4. Проверьте название, Markdown и ссылки на источники.
5. Убедитесь, что до нажатия `Сохранить материал` новый материал отсутствует.
6. Сохраните черновик и проверьте связь с выбранной задачей.

Логи вызовов находятся в Supabase Dashboard в разделе Edge Functions.
Счётчик использования можно проверить запросом:

```sql
select user_id, status, model, created_at
from public.ai_assistant_requests
order by created_at desc
limit 20;
```
